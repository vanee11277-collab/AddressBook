# AddressBook

Aplicación de agenda telefónica desarrollada en Java.
Actualización desde feature-contactos


---

## Instalación y ejecución

1. Clonar el repositorio:
2. git clone https://github.com/vanee11277-collab/AddressBook
Abrir el proyecto en IntelliJ IDEA.

Ejecutar la clase `Main.java`.

---

## Uso del programa

El programa funciona mediante un menú interactivo que permite:

- Listar contactos  
- Crear contacto  
- Eliminar contacto  
- Guardar y salir  

Los contactos se almacenan en un archivo de texto.
